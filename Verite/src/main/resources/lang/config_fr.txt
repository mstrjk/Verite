chat.filter = ---- Veritédoux (Filtre de chat) ----
chat.filter > auto.update.eve = Met automatiquement à jour les fichiers de configuration .eve lorsque de nouvelles entrées sont ajoutées.\nLorsque cette option est activée, toutes les entrées personnalisées seront écrasées et/ou supprimées lorsque\nles fichiers .eve seront remplacés par leurs versions mises à jour.
chat.filter > block.message = Les avertissements affichés lorsqu'un message est bloqué par le filtre de chat\nPrend en charge les codes & et les couleurs hexadécimales &#RRGGBB. Utilisez @prefix pour insérer le préfixe choisi.\nDéfinissez le contenu d'une ligne sur "" si vous gérez vous-même l'avertissement.
value:chat.filter > block.message = "@prefix Votre message n'a pas été envoyé. Merci de garder un ton cordial dans le chat."
value:chat.filter > repeat.message = "@prefix Vous avez déjà envoyé ce message. Merci d'attendre un moment avant de le répéter."
chat.filter > general.lang = Avertissement de blocage lié à l'automutilation\nPour des raisons de sécurité, le message de blocage lié à l'automutilation ne peut pas être modifié.\nCela garantit que les utilisateurs reçoivent toujours les conseils et le soutien appropriés\nlorsqu'ils sont confrontés à du contenu lié à l'automutilation.\nQuelles langues doivent faire l'objet d'une vérification du contenu ?\nLa détection des grossièretés est entièrement désactivée par défaut, car certains serveurs acceptent parfaitement\nl'usage occasionnel de jurons. Ajustez ces paramètres en fonction du niveau de tolérance de votre serveur.
chat.filter > advanced > keep.chat.readable = Indique s'il faut bloquer les messages susceptibles de rendre le chat illisible\nBloque les 𝓅𝑜𝓁𝒾𝒸𝑒𝓈 𝒻𝒶𝓃𝓉𝒶𝒾𝓈𝒾𝓈𝓉𝑒𝓈 susceptibles de perturber le chat,\nmême si le message peut être détecté par le filtre de chat.\nLes emojis ne sont pas bloqués.
chat.filter > advanced > block.possible.spam = Utilise le tokenizer de Verité pour détecter et bloquer les éventuels messages de spam et publicités.\nAttribue un score à un message selon la mesure dans laquelle son vocabulaire paraît promotionnel\nplutôt que conversationnel.\nIl s'agit d'une heuristique qui sous-estime souvent le spam dans certains contextes.
chat.filter > advanced > block.repeat.messages = Bloque les messages répétés. Cette fonctionnalité est conçue pour empêcher les utilisateurs de spammer\nle chat avec des messages identiques ou similaires. Tous les paramètres ci-dessous ne s'appliquent\nque lorsque cette option est activée.
chat.filter > advanced > block.repeat.exact = Bloque un message identique à un message récent du même utilisateur.\nLa comparaison ignore la casse, les accents et les lettres répétées ; "HELLO", "hello" et "helllo"\nsont donc tous considérés comme le même message.
chat.filter > advanced > block.repeat.near = Bloque un message qui est simplement similaire, sans être identique, à un message récent du même utilisateur.\nLe degré de similarité nécessaire pour qu'il soit considéré comme correspondant est défini\npar block.repeat.similarity.threshold ci-dessous.
chat.filter > advanced > block.repeat.history.size = Nombre de messages récents de chaque utilisateur mémorisés et vérifiés afin de détecter les répétitions.\nUtilisez -1 pour mémoriser tous les messages, ou 0 pour désactiver complètement la détection des répétitions.
chat.filter > advanced > block.repeat.window.ms = Durée pendant laquelle un message mémorisé continue d'être considéré comme une répétition, en millisecondes.\nLes messages plus anciens sont ignorés.\nUtilisez -1 pour ignorer le temps et mémoriser les messages indéfiniment, ou 0 pour désactiver complètement\nla détection des répétitions.
chat.filter > advanced > block.repeat.similarity.threshold = Pour la détection des répétitions similaires : degré de ressemblance requis entre deux messages pour qu'ils comptent comme une répétition.\nValeur comprise entre 0 et 1, où 1 signifie identique. Plus élevée = plus stricte (moins de blocages) ;\nplus faible = plus agressive.
chat.filter > advanced > block.unsupported.languages = Bloque les langues que Verité ne prend pas encore en charge\nNous prenons actuellement en charge l'anglais, l'espagnol, le français, l'italien, le portugais et l'allemand.\nToutes les autres langues seront bloquées si ce paramètre est activé.
chat.filter > advanced > language > known.word.weight = Poids d'un mot reconnu par le dictionnaire d'une langue mais absent\nde la table de fréquence. Plus la valeur est élevée, plus l'appartenance au dictionnaire compte.
chat.filter > advanced > language > unknown.word.weight = Poids minimum d'un mot absent de tous les dictionnaires et de la table.
chat.filter > advanced > evasion = Désactiver les passes de détection de contournement peut réduire la latence de quelques µs.
chat.filter > advanced > use.profanity.confidence = Le seuil de confiance pour les grossièretés détermine le niveau de confiance minimal\nrequis avant qu'un message soit considéré comme vulgaire.

moderation > use.rank.weights = Compare le poids des groupes LuckPerms afin d'empêcher le personnel de sanctionner des rangs égaux ou supérieurs.\nLes opérateurs sont toujours considérés comme le rang le plus élevé, quel que soit leur poids LuckPerms.
moderation > auto.ban.alts = Bannit automatiquement les comptes secondaires d'un joueur banni, que celui-ci\nait été banni par IP ou non. Nous déconseillons l'utilisation de cette option sur les serveurs\noù plusieurs utilisateurs distincts partagent la même adresse IP.
moderation > muted.command.blacklist = Commandes qu'un joueur réduit au silence ne peut pas utiliser. Si votre serveur est hébergé sur un réseau avec\ninjection via proxy, Verité peut ne pas réussir à bloquer ces commandes, ce qui signifie que l'utilisateur\nréduit au silence pourrait malgré tout encore les utiliser.
moderation > expire.warns.after = Durée pendant laquelle un avertissement reste actif avant d'expirer.
moderation > exempt = Compare le poids des groupes LuckPerms afin d'empêcher le personnel de sanctionner des rangs égaux ou supérieurs.
moderation > shared.ip.scan.limit = Nombre maximal de comptes à afficher lors d'une recherche d'adresses IP en double.

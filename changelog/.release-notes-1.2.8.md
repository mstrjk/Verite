- Rebuilt vlex9 tokenizer. File size dropped from 275 MB to 48 MB, it now covers only the 6 supported languages instead of 15.
- Merged the three dialect tokenizers into the main one. Dialect coverage was widened while rebuilding; Panamanian and Dominican Spanish were especially thin before.
- Removed the dedicated advertisement model. `block.possible.spam` is unchanged and still works.
- Rewrote word segmentation. Full message processing went from ~1630ms to ~390ms.
- PATCH: Segmentation could not split `iam` into `i am`. Very common short words were being scored the same as rare ones. Fixed.
- Release assets moved from Verite_Public to the main repository.
- Four files are deleted from existing installs on upgrade: the three dialect tokenizers and the advertisement tokenizer.
- Hover over a player's client in the join notice to see their protocol, version, connecting address, and locale.
- `/history` is now paginated at 5 per page, with clickable buttons to page through and sort by date, punishment, or duration.
- Hover a punishment in `/history` for its full record, or click it to open one. Also available as `/punishment <id>`.
- Blocked messages are now logged to console with the word that matched them.
- Rewrote every console message with a full stack trace on errors rather than a one-line summary.
- Console output is now coloured. Honours `NO_COLOR`; see the Installation page.
- PATCH: Some messages said they were disabling a feature and then carried on anyway.
- PATCH: Per-message filter timings were being written to console on every single message, including the message itself.
- PATCH: `(inactive)` and `(expired)` punishments were the same thing shown under two different words. They now both read `(expired)`.
- Added a web dashboard. Run `/verite dashboard` for a private link.
- Manage punishments, players, and your entire configuration from the dashboard.
- Search any player by name or UUID, including ones who have never joined the server.
- Added `general.dashboard.url` for servers that host the dashboard themselves.

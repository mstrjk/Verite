- Rebuilt vlex9 tokenizer; File size dropped from 275 MB to 48 MB; now covers only the 6 supported languages instead of 15.
- Merged the three dialect tokenizers into the main one. Dialect coverage was widened while rebuilding; Panamanian and Dominican Spanish were weak before.
- Removed the dedicated advertisement model. `block.possible.spam` is unchanged and still works. (Pending removal in 1.3.0)
- Rewrote word segmentation. Full message processing went from ~1630ms to ~390ms (p99 over 500 characters).
- PATCH: Segmentation could not split `iam` into `i am`. Very common short words were being scored the same as rare ones.
- Release assets moved from Verite_Public to the main repository.
- The three dialect tokenisers and advertisement tokeniser were removed.
- Hover over a player's client in the join notice to see their protocol, version, connecting address, and locale.
- `/history` is now paginated at 5 per page, with clickable buttons to page through and sort by date, punishment, or duration.
- Hover a punishment in `/history` for its full record, or click it to open one. Also available as `/punishment <id>`.
- Blocked messages are now logged to console with the word that matched them.
- Rewrote every console message with a full stack trace on errors rather than a one-line summary.
- Console output is now coloured. Honours `NO_COLOR`; see the Installation page.
- PATCH: Some messages said they were disabling a feature and then carried on anyway.
- PATCH: `(inactive)` and `(expired)` punishments were the same thing shown under two different words. They now both read `(expired)`.
- Added a web dashboard. Run `/verite dashboard` for a private link.
- Added `general.dashboard.url` for servers that host the dashboard themselves.
- Added `config.language`. Set it to `en`, `es`, `fr`, `it`, `pt` or `de` to run the whole plugin in that language. Requires a full restart.
- Translated every message into Spanish, French, Italian, Portuguese, and German.
- Replaced the chat component layer with our own serialiser, so hover and click text now works identically on Bukkit, Spigot, Paper, and Folia.
- PATCH: `/veriteflag` reported the same message whether a change applied instantly or needed a reload. ...Then moved `/veriteflag` to `/verite config <flag> [<value>]`. 
- Removed dead Secret.java file
- Fixed deprecated API usages
- `/verite config` can now edit every true/false and numeric key in `config.yml`, by short name or full dotted path, instead of a fixed list.
- `/mute *` now freezes global chat, the same as `/chatmute`. It requires `veritesauver.chatmute`.
- PATCH: InvSee disabled itself on 26.3 because `CraftItemStack.asBukkitCopy` changed parameter type.
- PATCH: Click and hover text did nothing on 1.21.5 and newer. Minecraft renamed the chat event fields in 1.21.5 and the old names were silently discarded by the client.
- PATCH: Text after a `</click>` or `</hover>` tag inherited the click or hover when a colour tag was opened inside the block.
- PATCH: `/showbarriers` and `/showlight` crashed on Bukkit, Spigot and CraftBukkit. They used a Paper-only particle class with no fallback.
- PATCH: The startup line for the resolved release printed a raw `%supported%` placeholder in English.
- Increased max supported Paper version to 26.3.
- WARN: The next update, 1.3.0, will remove all support for Minecraft versions under 1.21.6. 1.2.8 will be the last version to support the 1.19-1.21.5 chain. Please plan accordingly.
